# SK Home

A home screen for one Samsung TV, run as a [TizenBrew](https://github.com/reisxd/TizenBrew) app module.
Big tiles for the Fire TV Cube and its apps, TizenTube, plus the time, weather and heating.
The tiles that switch the TV's input or drive the Fire TV call a small helper on a PC on the same home network;
this only works on the network it was made for.
